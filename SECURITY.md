# Security Policy

SIDRA OS connects supported AI clients to an authorized computer, so security reports are treated seriously.

## Reporting a vulnerability

Please **do not open a public GitHub issue** for a suspected security vulnerability.

Email **support@sidra-ai.com** with the subject line **Security Report** and include, where possible:

- affected SIDRA OS version
- operating system
- clear reproduction steps
- expected vs. observed behavior
- potential impact
- screenshots or logs with credentials, tokens, personal data, and other secrets removed

We will review the report and coordinate any follow-up or disclosure directly with the reporter.

## Public product questions

For non-security questions, ideas, and product feedback, use GitHub Discussions or the support paths described in [SUPPORT.md](SUPPORT.md).
