## Where to ask

- **Questions, ideas, and general feedback:** use GitHub Discussions.
- **Reproducible product bugs:** open an Issue using the bug report form.
- **Feature requests:** open an Issue using the feature request form.
- **Account, subscription, or private support:** email **support@sidra-ai.com**.
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md) and do not post sensitive details publicly.

Please never post passwords, API keys, activation keys, payment information, private files, or other secrets in GitHub Issues or Discussions.
