# Contributing to the SIDRA OS GitHub Community

Thank you for helping improve SIDRA OS.

This repository is the **public product showcase for commercial proprietary SIDRA OS**. It is not the SIDRA OS source-code repository.

## Best ways to contribute

- **Questions and workflows:** use [GitHub Discussions](https://github.com/sidra-ai-development/sidra-os/discussions).
- **Reproducible product bugs:** open an Issue using the bug report form.
- **Feature requests:** open an Issue using the feature request form.
- **Documentation or showcase corrections:** open an Issue first so we can confirm the intended change.
- **SCODE source contributions:** use the open-source [SCODE repository](https://github.com/sidra-ai-development/scode).

## Pull requests

Pull requests to this repository should be limited to public showcase/documentation improvements that have been discussed first. Pull requests do not grant or imply access to SIDRA OS proprietary source code.

## Security

Never report a vulnerability publicly. Follow [SECURITY.md](SECURITY.md).

## Private support

For account, subscription, or private support, email **support@sidra-ai.com**.
